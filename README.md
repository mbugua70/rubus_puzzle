# Rubus Puzzle

## Setup

```bash
npm install
npm run dev       # start dev server
npm run build     # production build
npm run preview   # preview production build
npm run lint
```

## Assets

- Puzzle images: `public/puzzleImage/`
- Sounds (optional): `public/sounds/` — `countdown.wav`, `go.wav`, `correct.wav`, `wrong.wav`, `timeout.wav`, `result.wav`, `music.wav`

## Keyboard controls

| Key | Action |
|---|---|
| `Enter` | Start game |
| `C` | Mark correct |
| `W` | Mark wrong |
| `S` | Skip puzzle |
| `Space` | Pause / resume |
| `R` | Restart |
| `F` | Fullscreen |
| `M` | Mute |
